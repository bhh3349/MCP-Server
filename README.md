# MCP-Server

完整的本地 MCP 系统——完全控制 PC，基础工具开箱即用，可扩展插件 / 技能 / 连接器。

> **概念**：MCP Server 是本地完整系统。Bridge 只是它的一条通道（平时关闭，启动时打开），用于连接网关。一个网关可挂多条信道。

## 架构

```
┌─────────────────────────────────┐
│ MCP Server（本地完整系统）        │
│ - 基础工具：文件 / 命令 / 系统    │
│ - 可扩展：插件 / 技能 / 连接器    │
│ - Bridge 通道：连网关（按需打开） │
│ - 一键部署网关（附带功能）        │
└──────────────┬──────────────────┘
               │ 信道（两步建立）
┌──────────────▼──────────────────┐
│ 网关（一对多条信道）              │
└──────────────┬──────────────────┘
               │ 配对码 join
┌──────────────▼──────────────────┐
│ 网页 AI                          │
└─────────────────────────────────┘
```

## 快速开始

```bash
npm install
npm run dev          # stdio 模式（给本地 MCP 客户端用）
```

## 工具

| 工具 | 说明 |
|------|------|
| `read_file` | 分页读文件 |
| `write_file` | 原子写文件（支持 SHA-256 前置校验） |
| `list_files` | 列目录 |
| `file_hash` | 文件 SHA-256 |
| `exec` | 执行 shell 命令（支持后台任务） |
| `job_output` / `job_kill` | 后台任务管理 |
| `system_info` | 主机信息 |
| `health` | 健康检查 |

## 环境变量

- `MCP_SERVER_ROOT` — 文件工具的根目录（默认 cwd）
- `MCP_SERVER_PORT` — HTTP 模式端口（默认 38727）

## 技术栈

- TypeScript + Node.js 20+
- `@modelcontextprotocol/server` v2（官方 SDK）
- Zod 参数校验
